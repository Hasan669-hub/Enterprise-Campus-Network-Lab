# Enterprise Campus Network Lab

## Overview

This project demonstrates the design and implementation of a small enterprise campus network using Cisco IOS in PNETLab.

## Network Features

- VLAN Segmentation
- Inter-VLAN Routing
- EtherChannel (LACP)
- DHCP
- NAT/PAT
- Default Route
- SSH
- ACL
- Port Security
- Rapid PVST+

## Topology

Topology image is available in the images folder.

## Devices

- 1 Router
- 1 Layer 3 Switch
- 2 Access Switches
- Multiple Clients

## Verification

Configuration verification outputs are available inside the verification folder.

## Skills Demonstrated

- Enterprise Network Design
- Layer 2 Switching
- Layer 3 Routing
- Network Security
- Network Troubleshooting
